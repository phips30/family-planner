# Family-Planner

Open source Android and iOS application to ease daily family planning.
The first version containg a shopping list tool where multiple family members can collaborate.


## Technologies used
* GoLang:     go1.24.0 linux/amd64
* Postgres:   17.4
* MongoDb:    8.0.6


## Project structure
| Folder | Description| 
|----------|----------|
| app   | Android and iOS application written in react native to be cross platform compatible   |
| backend   | Backend written in Golang in a modular monolith structure   |
| deployment | Golang CLI for deploying the application |
